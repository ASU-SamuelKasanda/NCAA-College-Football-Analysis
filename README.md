# College Football Data Analysis

## About

This project is a Python-based data analysis of NCAA Division I college football programs. Using Python dictionaries and data analysis techniques, the project explores university enrollment data and team information to uncover insights related to college football programs.

The analysis focuses on working with structured datasets, retrieving and comparing information, and answering data-driven questions using Python. This project demonstrates the ability to manipulate data structures, perform exploratory analysis, and apply programming concepts to real-world sports data.

## Technologies Used

* Python
* Jupyter Notebook

## Skills Demonstrated

* Python Programming
* Data Analysis
* Dictionaries and Data Structures
* Data Exploration
* Loops and Conditional Statements
* Problem Solving
* Sports Analytics

## Project Highlights

* Analyzed NCAA Division I football datasets.
* Explored relationships between university enrollment and football programs.
* Retrieved and interpreted data using Python dictionaries.
* Applied programming techniques to answer analytical questions and generate meaningful insights from structured data.
